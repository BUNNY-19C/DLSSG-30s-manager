# 上游 0.4.0 适配

核对日期：2026-10-15。上游发布提交 `6f047bdc885e861575e8b049413ca31dc171a924`，官方 [Release 0.4.0](https://github.com/sdli1995/dlssg_for_sm86/releases/tag/0.4.0)；README 核对到提交 `6dcfd54c51e7fc2eb4fe25e5bb16044809c647b5`。此适配包含在管理器 v1.11.0 中。

## 已实现

- 下载固定适配的 `0.4.0` tag，使用 Release 完整 ZIP，新增 GitHub 资产重定向主机；逐文件源作为无超分负载的后备。
- 原生负载拆为代理、INI 和 `dlssg_sm86/` 六个运行文件，其中两个 SR 文件仅在完整包中。四个基础组件缺失时源不可部署；SR 文件缺失时不能开启超分。
- 所有 DLL 验证签名完整性，并分别要求项目或 NVIDIA 签名；镜像的项目文件继续匹配原证书指纹。
- 新版部署清理已确认归属的多余代理。保留旧版 0.3.x 待机共存、本地 310.1 使用与恢复能力；停止下载 310.1。
- 逐文件部署、记录、检测、恢复嵌套运行文件；外来文件先备份，未知文件不做目录级删除。部分复制失败也保留已写文件与备份记录。运行目录中的链接不会被跟随写入或清理。
- INI 按节写入，分别处理 `[Runtime] Mode` 与 `[SuperResolution] Mode`；`Optimized`、`Preset` 写入 `[DLSSG]`。
- 新增 DLSS / XeSS、预设 C、光流精度、无 HUD 输入、INT8 超分、逐帧 GPU 计时。XeSS 渲染倍率钳到 2X，保留原先 DLSS 倍率设置供切回时使用。
- 新建配置优化档位为 2，旧配置已有档位继续保留。复制、快照与持久化包含新字段。
- 修正异环提示：旧版双代理方案不能直接套用到 0.4.0；新版入口需游戏内验证。
